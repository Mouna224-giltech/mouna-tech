MOUNA TECH — site web

Fichiers :
- index.html : page principale
- style.css : design

Pour tester :
1. Ouvrez index.html avec Chrome.
2. Pour mettre le site en ligne, envoyez ces fichiers sur un hébergeur.

À personnaliser ensuite :
- remplacer les produits exemples par les vrais produits ;
- ajouter les photos ;
- ajouter les prix en GNF ;
- ajouter l'adresse et les horaires si nécessaire.
